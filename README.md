## Controles

- Siguiente: → ↓ PageDown, Espacio, Enter
- Atrás: ← ↑ PageUp, Backspace
- Inicio / Fin: primer y último paso
- F: pantalla completa
- `#paso-N` en la URL abre en ese paso
- v2 y v3: rueda o + / − / 0 para zoom, arrastrar para mover, [ y ] o Mayús+arrastrar para girar

Figuras de v1 y v2 hechas con la skill [anatomy](https://github.com/wheresryan22/anatomy); la de v3, con [specimen](https://github.com/julianolarteramos/specimen).
